# Market Basket Analysis (Product Co-Purchase Pairs)

## 📌 Project Overview

This project analyzes transaction-level product data to identify **products that are frequently purchased together**.

The analysis aims to uncover product associations that can support business strategies such as **cross-selling, product bundling, and store layout optimization**.

The analysis was conducted using **Google BigQuery (GoogleSQL)** with CTEs, self-joins, distinct counting, filtering, and aggregation techniques.

---

## 🗂️ Dataset

The analysis uses sales invoice item records from the `item` table.

### Key Columns

| Column       | Description                                                |
| -------------| ---------------------------------------------------------- |
| `invoice`    | Unique transaction/invoice identifier                      |
| `item_code`  | Unique product identifier                                  |
| `qty`        | Quantity of the product purchased in a transaction         |  
| `net_amount` | Net sales amount generated by the product in a transaction |

The analysis primarily uses:

* `invoice`
* `item_code`

to identify which products were purchased within the same transaction.

## 🧮 SQL Techniques Demonstrated

The project demonstrates practical SQL techniques commonly used in Data Analyst workflows.

### CTE

Used to structure the analysis into logical steps.

```sql
WITH basket AS (
    SELECT DISTINCT
        invoice,
        item_code
    FROM `project.dataset.item`
)
```

### Self JOIN

Used to generate product combinations within the same invoice.

```sql
FROM basket a
JOIN basket b
    ON a.invoice = b.invoice
    AND a.item_code < b.item_code
```

The `a.item_code < b.item_code` condition ensures that the same product pair is not counted twice in reversed order.

For example:

```text
SA015-2 → SA1-1CS
```

and

```text
SA1-1CS → SA015-2
```

are treated as the same product pair.

### COUNT DISTINCT

Used to count the number of unique invoices where each product pair was purchased together.

```sql
COUNT(DISTINCT a.invoice)
```

### Aggregation

Used to calculate the total co-purchase frequency for each product pair.

```sql
GROUP BY
    item_a,
    item_b
```
